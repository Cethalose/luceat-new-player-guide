# Luceat New Player's Guide

Static first release for LUC-38A: Character Choice Guidance.

## Contents

- `index.html` is the public guide.
- `styles.css` contains the site styling.
- `.nojekyll` keeps GitHub Pages from applying Jekyll processing.
- `NOTICE.md` records attribution and independence notices.

## Source Boundary

This repository is intentionally content-only. It does not include Luceat application source, internal planning docs, infrastructure configuration, credentials, private validation artifacts, or unpublished Board/governance material.

The guide was drafted from Luceat's active `dnd-5e-srd-5.1` data files and ordinary character creation/progression behavior.
